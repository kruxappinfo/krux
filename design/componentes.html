Fase 2. Cada pieza usa el CSS real de app_2.css y los constructores de map-ui.js. Hoy conviven con las versiones propias de cada sección; cada sección las adopta en su fase, nunca todas a la vez.

Botones

Un único sistema: píldora y peso 600. La jerarquía la da el color, nunca la forma: principal para la acción que cierra la tarea, secundario para alternativas, terciario para acciones de bajo peso y destructivo solo para borrar. Un único principal por pantalla.

Selector segmentado

Para alternar vistas o filtros excluyentes de un mismo dato (semana / mes / año). Las etiquetas nunca se cortan: si las opciones no caben en una fila, el mismo control pasa a chips en varias líneas, con todas las opciones a la vista y sin perder la selección ni el teclado.

Pulsa una opción o usa las flechas ← →.

Transición de segmentado a chips

El mismo selector en contenedores de distinto ancho. El cambio se decide midiendo, no con un punto de corte fijo: depende de las etiquetas reales.

el.innerHTML = kxSegmentedHTML({ label: 'Periodo', value: 'mes', items: [
  { value: 'semana', label: 'Semana' }, { value: 'mes', label: 'Mes' }, { value: 'año', label: 'Año', disabled: true } ] });
kxBindSegmented(el.firstElementChild, value => …);   // teclado, selección y paso a chips
// El contenedor debe poder encogerse (min-width: 0 en celdas de grid o flex); si no, el control crece en vez de pasar a chips.

Filtros (chips)

Para filtros que se pueden combinar o listas largas que se desplazan en horizontal. Ya en uso en Buscar y Notificaciones.

Campos de formulario

Etiqueta siempre visible encima y ayuda debajo; el marcador de posición es breve y nunca sustituye a la etiqueta. Cada estado se distingue sin depender del color: el foco engrosa el borde, el error añade icono y texto y el deshabilitado usa trama discontinua sobre gris piedra. El borde del campo tiene un contraste de 3:1.

Etiquetas

Estado o atributo de un elemento, sin acción. Siempre icono y texto: el color nunca es el único aviso. El texto usa una tinta algo más oscura que el icono para llegar a 4,5:1 sobre el fondo suave. Si el texto no cabe, pasa a otra línea.

Calculado en esta página a partir de los estilos reales. Mínimos: 4,5:1 para el texto y 3:1 para el icono.

Filas de dato y secciones

Fila con icono, etiqueta y valor; el valor largo se parte en varias líneas en vez de cortarse. La versión pulsable es un botón con flecha. Varias secciones seguidas llevan un separador fino.

Secciones con separador

Franja de datos técnicos

Tres datos con icono, valor y etiqueta. Un dato que falta se muestra atenuado, con borde discontinuo de 3:1, e invita a completarlo; un dato que existe también puede ser pulsable si se puede corregir.

Acciones

Acciones principales en rejilla (registrar ascenso, proyecto, comentarios, compartir) y acciones secundarias en lista. Estados: normal, principal, marcada, con contador, ocupada (conserva su etiqueta y solo el icono pasa a giro), deshabilitada y foco. El deshabilitado cambia de forma (sin relleno, contorno fino), no solo de color.

Estados

Carga, vacío, error con reintento, sin sesión y resultado de una acción. Nunca una tarjeta vacía: cada estado dice qué pasa y, si hay salida, ofrece la acción.

Carga parcial

Los datos que ya existen se muestran de inmediato; solo lo que falta lleva esqueleto.

Avisos

Un único sistema en toda la app: showToast. Tonos semánticos de la marca (sin el índigo heredado); el aviso lleva además un triángulo para distinguirse del error sin depender del color. showSectorToast, showRDToast y showDevToast ya lo llaman por dentro. Las páginas de administración tienen el suyo propio (Fase 6).

Calculado en esta página a partir de los estilos reales. Mínimos: 4,5:1 para texto, 3:1 para el icono frente al fondo.

Popups de escritorio

Cabecera fija con título y cierre, contenido que se desplaza por dentro y acciones fijas abajo. Tres anchos según la cantidad de contenido (280, 360 y 420 px). La altura nunca supera el hueco disponible, y los separadores solo aparecen cuando hay contenido por debajo o por encima. Se cierran con ✕ o Escape.

Títulos: mayúscula inicial y el nombre tal como se escribe, nunca todo en mayúsculas (Valeria, Pico de la Muela, El manantial). Las mayúsculas completas se reservan para las etiquetas pequeñas de sección, como «SECTORES».

Según la cantidad de contenido

Mismo contenido largo en los tres tamaños

Misma cabecera, mismos márgenes (20 px), misma tipografía y el mismo par de acciones; solo cambia el ancho. Las acciones van en tamaño normal (44 px): con ratón no hace falta el grande y así queda más sitio para el contenido. Cuando no caben, pasan a dos filas sin cortar el texto.

Sobre el mapa, cada popup se coloca junto al elemento seleccionado. En móvil esta misma información va en la hoja inferior, y a 320 y 390 px el popup se limita al ancho de la pantalla menos 32 px.

Gráfico de grados · Fase 3

En la app este gráfico está en las fichas de sector; la ficha de escuela conserva su donut y su tiempo originales. Distribución de vías por grado con los datos reales de cada escuela: todos los grados por separado, con los colores originales. Al pulsar una barra se ven el grado, sus vías exactas y su porcentaje; volver a pulsarla, la ✕ o Escape quitan la selección. Se puede arrastrar el dedo para recorrer grados estrechos, y con teclado basta con las flechas. Sin selección, el resumen da información que el gráfico no muestra: el rango (del grado más fácil al más difícil), el grado hasta el que llega la mitad de las vías y el grado con más vías.

Filtro activo en el mapa

«Ver las N vías» filtra el mapa actual por ese grado (y por el sector, si viene de una ficha de sector) y cierra la ficha para dejar ver el mapa. Una píldora bajo el buscador indica el grado activo, cuántas vías son y de dónde; tocarla vuelve al gráfico con ese grado ya seleccionado y la ✕ quita el filtro. Mover el filtro de rango del mapa o pulsar «Todos» también lo retira.
